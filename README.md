# TIC TAC TOE

## Two player tic-tac-toe game using c++(CMake)

## Steps for building and running the game:

### Step 1: Create a build directory(preferrably outside the repo)
``` bash
mkdir build
```

### Step 2: Generate build files using Cmake
``` bash
cmake ./{path-to-repo} -G Ninja
```

### Step 3: Run the executable
``` bash
./{build_tree}/tic_tac_toe
```

Now enjoy the game!!
